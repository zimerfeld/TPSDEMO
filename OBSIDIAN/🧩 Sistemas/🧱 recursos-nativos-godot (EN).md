# 🧱 Native Godot Resources Used in the Project

> Documented on 2026-06-20. A survey of **which NATIVE Godot nodes and resources**
> the game uses directly (e.g.: `StaticBody3D`, `CollisionShape3D`,
> `MeshInstance3D`). Gathered from the `extends` of the `.gd` files and the `type=` of the `.tscn`,
> **excluding** the `godot_ai` addon (third-party MCP plugin) — the slice below is the **game's**.

The project **has no custom C++/GDExtension node**: every class is native to Godot.
The only in-house abstractions are `RefCounted` scripts of **pure logic with no node**
(`BodyParts` + the body-plan subclasses `BodyPartsBiped`/`Quadruped`/`Crawler` + the
factory `BodyPlans`, `WeaponParts`, `LimbConfig`, `LaserShooter`, `CannonShooter`), which
just orchestrate the native nodes. See [[🩸 dano-localizado (EN)|Localized Damage]] and
[[🦿 limb-colliders-gd (EN)|limb_colliders.gd]] for the canonical example: a `Node3D` that
**assembles** native `StaticBody3D` + `CollisionShape3D` + `BoneAttachment3D`.

> Counts in parentheses = number of occurrences in `type=` across the game's scenes
> (snapshot 2026-06-20), useful only as a sense of frequency.

## Physics and collision

The project's most used group (a reflection of shooting + per-limb localized damage).

| Node/Resource | Use |
|---|---|
| `CollisionShape3D` (658×) | shape of every collision — by far the most frequent |
| `StaticBody3D` (13×) | limb hitboxes (`limb_colliders.gd`) and scenery |
| `CharacterBody3D` | `player`, `red_robot`, `bullet`, `bomb`, `criatura_alada` |
| `RigidBody3D` | `part.gd` (red_robot debris) |
| `Area3D` | `door.gd`, triggers, `PlayerDetectionArea` |
| `BoxShape3D` (118×) · `CylinderShape3D` · `SphereShape3D` · `CapsuleShape3D` | shapes generated by `make_shape()` and by scenery |
| `CollisionPolygon3D` · `SeparationRayShape3D` · `RayCast3D` · `PhysicsMaterial` | occasional cases (laser raycast, friction) |

## Base classes of the scripts (`extends` of a native node)

The most direct slice: game scripts that **inherit** a native node.

|---|---|
| `CharacterBody3D` | `player.gd`, `red_robot.gd`, `bullet.gd`, `bomb.gd`, `criatura_alada.gd` |
| `RigidBody3D` | `part.gd` |
| `Area3D` | `door.gd` |
| `Camera3D` | `camera_noise_shake_effect.gd` |
| `MultiplayerSynchronizer` | `player_input.gd` |
| `SkeletonModifier3D` | `procedural_aim.gd` |
| `CPUParticles3D` | `part_disappear.gd` |
| `CanvasLayer` | `health_bar.gd`, `enemy_health_bar.gd` |
| `Node3D` | `level_*.gd`, `blast.gd`, `limb_colliders.gd`, `flying_forklift.gd` |
